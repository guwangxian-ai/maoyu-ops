# AI 接入中心

入口 `/ai-access`，需要系统登录。公开说明 `/ai`、AI 可读 Markdown `/ai/guide.md` 和完整技能包 `/ai/skills/xianyu-operations.zip` 不需要登录，但不包含凭证或业务数据。

## 使用流程

1. 复制接入说明链接给支持远程 MCP 的 AI 客户端。
2. 优先复用同实例有效密钥；需要新凭证时，在“客户端密钥”中创建独立密钥，默认四个业务域只读，有效期 1–90 天。写入按分享、卡券、发货、账号启停等能力分别勾选；权限覆盖当前系统用户所属业务数据，暂不细分到单个闲鱼账号。
3. 将密钥保存到客户端私有凭证配置。Codex 配置从 `XIANYU_MCP_TOKEN` 读取；通用 JSON 提供占位符，按客户端格式适配。不要将密钥放进 URL、聊天或 Skill。
4. 下载并安装完整 Skill 目录，保留 `scripts`、`references`、`agents`。包内 `CONNECT.md`、配置模板、Python 依赖和服务器地址均属于本实例。
5. 连接 MCP 后先调用 `mcp_capabilities`。网站“验证密钥”仅验证本用户的 Token 和权限，不代表外部客户端已连接或闲鱼、网盘账号已授权。
6. 调用审计只保存工具名、状态、时长、错误代码和客户端 ID；独立操作回执另存参数摘要和脱敏结果，供只读恢复，不保存原始参数或密钥。无需使用时撤销对应密钥，后续 HTTP 请求立即失效，已经开始的业务不自动回滚。

当前是独立 Bearer Token 接入，不实现 OAuth 授权发现。需要 OAuth 的客户端不能直接自动授权。Skills 不会启动常驻运营、定时任务、付费模型或自行赋予发布/发货权限。

## 配置与实现

- `MCP_PUBLIC_BASE_URL`：可信实例地址；本地可为 `http://127.0.0.1:9000`，远程必须 HTTPS。子路径部署必须保留 `/xianyu-auto-reply`。接入文档绝不根据请求 Host 生成地址。
- `MCP_ALLOWED_HOSTS` / `MCP_ALLOWED_ORIGINS`：与实际反向代理地址一致。不要为方便接入设全通配符。
- `MCP_FILE_DIR`：持久化私有暂存目录，不能放在公开 static 中。
- 公共接口 `/ai/manifest.json` 是本项目接入信息格式，包含技能包版本和 SHA-256，不是 OAuth discovery。
- ZIP 使用固定文件白名单，不递归打包运行目录；缺失文件返回 503，非白名单返回 404。
- 管理接口 `/api/v1/mcp/connection`、`/connection/check`、`/tokens`、`/logs` 沿用网站登录与 owner 隔离。`/mcp` 只接受独立 MCP Token；数据库仅保存 Token 哈希。
- 2026.10.14.1 新增 `xy_mcp_operations`，沿用启动初始化，仅建新表，不改变现有业务数据。创建时显式刷新 MySQL 生成的时间戳，避免异步懒加载。
