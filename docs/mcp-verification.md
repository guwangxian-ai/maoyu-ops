## 真实业务验证

使用用户此前允许的独立测试目录和无业务内容的文本。测试范围内的分享均设置提取码和一天有效期。

1. 夸克：读取授权状态、真实文件列表；创建独立目录；上传测试文本；等待异步任务成功；核对文件并生成真实分享。
2. 百度：读取授权状态、真实文件列表；创建独立目录；上传、下载测试文本并逐字节比对；生成真实分享。
3. 本地卡券：创建、读取、删除临时文本卡券，测试数据已删除。
4. 多网盘完整链路：通过 MCP 上传同一份测试文本到资料模块 → 文件分析 → 同步夸克和百度 → 核验副本 → 创建双平台分享 → 生成卡券 → 读取卡券确认包含两个平台的链接和提取码。
5. 多网盘样例卡券已停用，并通过实际接口核对没有关联商品。样例资料名为 `闲鱼接口测试-MCP-20261012-214251-同步`，可在本机资料页面查看。两个网盘的独立测试目录保留；夸克当前接入不支持删除云端文件。

首次百度 MCP 上传曾被输入校验拒绝，未向网盘提交。原因是运行中的旧后端没有加载 FastAPI 新版 `UploadFile` schema 兼容修复；核对测试目录为空、正确重启后重试成功。没有将被拒绝的调用计作上传成功。

## 范围与证据

本轮没有真实上架/下架在售商品、发送买家消息或向订单发货，也没有测试付费 AI 上架任务。这些工具调用现有业务实现，后续应在明确的商品、账号、费用和运营授权范围内做平台验收。并不代表 245 个业务工具的每一种参数组合均经过真实外部操作测试。

审计回执不记录请求/响应正文；原业务服务仍沿用已有日志策略。MCP 不提供全部旧接口的统一幂等保证；结果未知时必须先查询原任务状态。多进程部署前仍需评估文件配额协调及业务后台任务的进程归属。

本机私有证据位于 Git 忽略目录，不提交分享地址或凭证：
