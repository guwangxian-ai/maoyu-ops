# 2026-10-25 上游更新整合

来源：[zhinianboke/xianyu-auto-reply](https://github.com/zhinianboke/xianyu-auto-reply)，沿用 AGPL-3.0 许可证和原作者署名。上次基线 `10fc70ebfd3c3b481cc1d6975153cc20ee746c3d`，本次整合至 `990f701fe03d7f62c3cf1fe571fc5bb6de57c778`，共四个上游提交；详细评估见 [更新评估](upstream-review-20261025.md)。

## 功能

- 新增后台用户登录审计：记录登录方式、成功/失败、时间和客户端 IP，仅管理员可查。与闲鱼账号上线日志分别展示。
- 新增邮件发送日志和筛选字典：记录触发原因和结果，不记录邮件正文或验证码。
- 数据库备份管理增加单条/批量删除、目录边界检查、事务失败补偿和中断恢复；下载支持登录过期后刷新令牌。
- 按上游指定账号 ID 过滤官方机器人消息，并在文字、图片和原始消息发送前检查接收方；正常买家与付款卡片仍进入原处理流程。
- 在线聊天的令牌和通信实现拆为独立模块，保持原连接行为。本次没有新增“扫码后自动补发商品”的队列。

## MaoYuOps 适配

采用三方合并，保留子路径 `/maoyu-ops/`、独立浏览器存储、MCP 权限与操作回执、网盘授权、卡券、商品在售快照、库存和 AI 回复规则。Skills 保持 `2026.10.23.3`，运营规则和用户暂停发布的状态不变；没有新增依赖。

- 解密聊天日志继续截取前 1000 字符；邮件日志结果最长 4096 字符，查询使用有上限的分页。没有启用自动备份或新增定时清理任务，也没有删除既有运营日志。
- 登录审计写入使用独立数据库事务，失败不会回滚认证会话。
- `TRUSTED_PROXY_IPS` 仅接受明确列出的代理 IP。腾讯云项目已核对网桥网关为 `172.18.0.1`；项目 Compose 配置允许该地址及 loopback，Nginx 覆盖 `X-Real-IP`，不信任用户提供的最左侧 `X-Forwarded-For`。迁移网络时应重新核对，不改全局 Docker 设置。
- Blob JSON 错误解析限制为 1 MiB，非法 JSON 返回可读错误；原有命名空间认证令牌保持兼容。
- 备份批量删除即使部分失败也返回 `deleted` 和 `failed_ids`。该页面管理应用备份，不代表每次部署需要备份；部署仍遵循 AGENTS.md 的逐次选择。

## 验证与部署

本地仅执行 Python 语法检查、TypeScript 检查和生产构建；功能回归在云端隔离容器运行，不连接生产数据库、不挂载授权或资料卷，不发送邮件或买家消息。新增 MySQL 表先在一次性数据库检查重复建表和字典初始化。
