# 商品合规与处罚处理

在选品、新发布、重发、变更商品内容或处理违规通知时读取。本文件保存核对方法和本项目经营范围，不是闲鱼完整禁售清单，也不保证通过审核。

## 分别核对三个条件

1. **平台是否允许交易。** 查适用的闲鱼规则、类目要求、当前公告和该商品已有处罚；核对的是实际商品/服务，不能只看品牌词、搜索是否有结果或竞品仍在售。
2. **是否有相应权利。** 核对具体文件及版本的许可证、商业再分发条件、教程和图片来源。曾经购买、自称“自己的”、以前卖过或软件开源，不单独证明转售权；已有可信证明且内容未变时直接复用，不让用户每换一个 Agent 都重新举证。
3. **能否如实交付。** 标题、描述、图片、规格、实际文件、卡券和 AI 承诺须一致。收费、免费、0.1 元、无外链或付款后发货只涉及定价和流程，不会使禁售商品变成允许交易的商品。用户批准和 MCP 写权限也不替代前两项。

核对深度随风险决定。普通低风险商品复用同版本有效记录；仅改价格/库存且没有新风险信号时，不机械重做选品研究。出现规则变更、来源/交付变更、投诉或处罚时，重新核对受影响结论。

## 海外 AI、账号服务与技术教程

- 本项目自动选品默认不做 ChatGPT/GPT、Claude/Claude Code、Cursor 等海外 AI 的账号/会员转售、代注册代充、合租，以及 API 密钥或中转访问转售。此为本项目降低风险的经营范围，不冒称这些名称被官方一律列入禁售名单。用户要求研究某类服务时可以调查和准备分析，不能把用户同意当作平台允许的证明。
- 自制 MCP 配置、编程或使用教程与账号交易分开判断。核查是否实际夹带账号、共享凭证、代理访问、破解、绕过付费或其他受限内容；标题写“教程”、声明“仅供学习”或不写产品名，均不改变实际交付性质。纯技术教程也需核对平台准入，不能承诺一定可发。
- 不因软件来自国外就统一判为禁售；不因国产、开源或竞品仍在售就统一放行。查不到完整黑名单时说明“公开资料尚不能确认”，不要编造官方规则或推定所有相关教程都被禁止。
- 检查最终标题、完整描述、每张图片的可见文字/截图/二维码及实际交付目录。清理公开链接按 [文案约定](listing.md#公开商品文案约定) 执行，交付包按许可保留来源和声明；不能靠删掉品牌、链接或免责声明掩盖仍然受限的交付内容。

## 收到处罚或发布被拒

1. 保存原商品 ID、账号、草稿版本、通知时间、处罚原文、所引规则及完整商品内容。区分“平台已处罚的事实”“平台明确指出的内容”和“推测的触发原因”；“政治敏感”这样的分类不能单独证明具体命中了某个品牌词，也不能直接认定误判。
2. 暂停相关内容的新发布、重发和批量复用。先查已有回执及平台状态，不能用换标题/谐音、拆字、藏图、二维码、换账号或改类目反复试审核。新处罚信号会使此前“可发布”的判断需要复核，过去成功上架不构成继续提交的依据。
3. 能独立完成的读取、资料核对、合规草稿和其他不受影响的已授权工作继续推进。暂停新发布不等于自动下架或删除现有商品；下架、删除、申诉提交和历史订单处理仍遵循相应授权，不擅自取消订单、补发或退款。
4. 若实际内容支持申诉，准备目录、教程样例、权利证明及具体争议点，请平台说明违规内容和适用规则。只使用可核验事实，不能替店主虚构“无账号/无代理/完全原创”等声明。申诉期限以该通知为准，不把某次通知的 15 天写成所有案件通用期限。
5. 获得复核结论、适用规则或实际内容变更后，更新记录再决定能否按原授权继续。明确不允许的内容不提交；高风险或已处罚商品仍无法确认时停在草稿，说明缺少哪项具体证据，不宣称“改好就不会封”。

## 记录与跨 Agent 续做

在 Git 忽略的私有运营目录记录：账号/商品或素材版本、检查时间、来源链接及规则版本、核对过的实际内容、已确认事实、待核实项、结论（可按授权继续/仅草稿/不提交）和理由。接手先查这些记录；同一内容、规则和授权未变时复用，不重复询问已批准的操作。尚未确认的结论不能被后一个 Agent 当作已通过。

Skill、公开接入说明和 MCP 使用提示帮助 Agent 决策，并非服务端逐项审核或禁售硬拦截。旧客户端必须更新技能/重读实时提示；未加载这些说明的 Agent 不能被视为已遵守。不要依赖单纯关键词脚本保证合规，也不以真实发布或买家消息做审核测试。
